Smart Learner · 安装说明

一款面向个人学习的桌面工具，包含：
· 首页：今日课程、知乎热榜与关注推送（每周一自动更新）
· 课程：资料管理、Markdown 笔记预览、PDF 阅读
· 整理：把课件整理成中文知识点笔记（支持导出 .md 到课程）
· 书僮：基于课程知识库的问答，支持“问问知乎:[问题]”检索知乎内容
· 设置：知乎 Access Key 与阿里百炼 API Key 管理

系统要求
· Windows 10 / 11（64 位）
· Microsoft Edge WebView2 运行时（Win11 自带；Win10 若缺失请先安装）
· 首次使用需在「设置」中填写知乎 Access Key 和百炼 API Key

安装选项
· 可自定义安装目录
· 可勾选创建桌面快捷方式
· 可在安装完成后直接启动

数据位置
· 用户数据默认保存在 桌面\SmartLearner（可在设置中修改）
· 卸载程序不会删除你的课程、笔记和聊天记录
