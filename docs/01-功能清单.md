# Smart Learner 功能清单 v1.0

> 状态：**待确认**　日期：2026-11-18　依据：D1–D19 决策记录
> 用途：冻结功能范围，作为架构设计与项目结构的唯一输入。

---

## 0. 一句话定位

**Smart Learner 是一个面向学生的桌面学习工作台**：首页看今日课表与知乎热榜，课程里管理资料并用「书僮」基于自己的知识库问答，把课件一键整理成中文知识点笔记。

---

## 1. 名词定义

| 名词 | 含义 |
|---|---|
| 课程 | 用户手动添加的学习科目，是**唯一真相源**；对应 `Documents/` 下一个同名文件夹 |
| 子文件夹 | 课程内的章节分组，可自由增删改名 |
| 笔记 | `.md` 文件，**可编辑** |
| 文档 | `.pdf` / `.docx` 文件，**只读预览** |
| 书僮 | 课程助手的名称，基于本地向量知识库问答 |
| 整理稿 | 「整理」页生成的 `.md` 文件，本质是笔记 |

---

## 2. 范围

### 2.1 做

- Windows 桌面端（WPF + MaterialDesignInXaml）
- PDF / DOCX 导入与只读预览
- Markdown 笔记的新建、编辑、导出
- 基于本地向量库的课程问答（RAG）
- 知乎热榜与关键词搜索
- 本地存储、离线可用

### 2.2 明确不做

| 不做 | 原因 |
|---|---|
| PPT / PPTX / 老式 .doc | 范围裁剪，只做 PDF + DOCX |
| 扫描件 OCR | 无文本层直接提示不支持 |
| 双窗翻译对照 | 已由 D16 取消 |
| 知乎 OAuth 登录 | 由 D6 取消，改用用户自填 Access Secret |
| 知乎知识库 RAG | 由 D7 取消，改本地向量 |
| 多用户 / 云同步 | 单人本地应用 |
| 移动端 / Web 端 | 不在赛题技术栈内 |

## 3. 功能清单

优先级：**P0 = 演示主线必须**；**P1 = 完整体验**；**P2 = 本期不做**。

### 3.1 外壳 S（7 条）

| ID | 功能 | 优先级 | 验收标准 |
|---|---|---|---|
| S-01 | 启动与离线优先 | P0 | 断网时应用**仍能启动**并进入首页；顶栏显示「离线」角标；不弹退出框、不退出进程 |
| S-02 | 顶栏 | P0 | 左侧显示图标 + 「Smart Learner」；右侧显示凭证状态（已配置/未配置）与设置入口；窗口可拖动、可最小化/最大化/关闭 |
| S-03 | 侧边栏导航 | P0 | 四项：首页 / 课程 / 整理 / 设置；当前项高亮；点击右侧内容区切换，切换耗时 < 200ms |
| S-04 | 明暗主题 | P1 | 顶栏一键切换明/暗；选择持久化；重启后保持；两套配色均为复古书香气（米白/墨色） |
| S-05 | 数据目录初始化 | P0 | 首次启动在桌面创建 `SmartLearner/` 及其子目录；目录已存在则直接复用；创建失败给出可操作提示 |
| S-06 | 全局状态中心 | P1 | 网络、凭证、限流三种状态全局唯一；各页面订阅同一份，不各自探测 |
| S-07 | 窗口状态记忆 | P1 | 记住窗口尺寸/位置/最大化状态，下次启动恢复；越界时回到主屏 |

### 3.2 首页 H（11 条）

| ID | 功能 | 优先级 | 验收标准 |
|---|---|---|---|
| H-01 | 课表空态 | P0 | 无课程时第一栏显示「添加课程信息以解锁课表提醒功能」引导卡，点击打开添加弹窗 |
| H-02 | 添加课程弹窗 | P0 | 字段：课程名、星期下拉（周一–周日）、开始/结束时间（HH:mm 下拉，15 分钟粒度）；「+」可追加一行；校验结束晚于开始、课程名非空、同星期同时间段不冲突；取消不写入 |
| H-03 | 今日课表 | P0 | 按当天星期筛选，按开始时间升序展示；无课显示「今日无课」；显示课程名与时间段 |
| H-04 | 课表持久化 | P0 | 写入 `courses.json`（UTF-8、原子写）；文件损坏时备份并重建为空表，不崩溃 |
| H-05 | 热榜 Tab | P0 | 调 `hot_list?Limit=10`；卡片含标题、摘要、缩略图（为空则不占位）；加载/失败/空数据三态齐全 |
| H-06 | 关注 Tab | P1 | 关键词 ≤ 6 个，标签形式，可删；每词调 `zhihu_search?Count=3`；结果按 `ContentID` 去重；请求串行且间隔 ≥ 200ms |
| H-07 | 推送缓存 | P1 | 写入 `cache/`，TTL 30 分钟；进入页面先渲染缓存再后台刷新；保留 7 天；更换 Secret 时清空 |
| H-08 | 卡片跳转 | P0 | 点击卡片用默认浏览器打开原始 URL（保留 UTM）；打开失败提示并支持右键复制链接 |
| H-09 | 离线/错误态 | P0 | 无网且有缓存：显示缓存 + 「离线模式 · 显示 X 前内容」；无网无缓存：「联网解锁更多内容」+ 重试；未配置 Secret：「配置后解锁」+ 跳设置；限流：「请求频繁，请稍后重试」 |
| H-10 | 骨架屏 | P1 | 请求期间显示骨架卡片，不出现空白跳动 |
| H-11 | 最近课件 | P1 | 首页展示最近打开的 5 个 PDF/笔记，点击直达 |

| ID | 功能 | 优先级 | 验收标准 |

### 3.4 课程 · 课程助手「书僮」A（8 条）

| ID | 功能 | 优先级 | 验收标准 |
|---|---|---|---|
| A-01 | 知识库创建 | P0 | 左侧列出 `Documents/` 全部文件（含子文件夹），批量勾选；显示类型、大小、是否已索引 |
| A-02 | 索引构建 | P0 | 本地抽取文本 → 分块（带课程/文件/页码元数据）→ `text-embedding-v4` → 写 `Database/<课程>/chunks.json` + `vectors.bin`；按文件 hash 增量，未变跳过 |
| A-03 | 索引进度 | P0 | 显示总文件数/已完成/失败数；可取消；失败文件可单独重试；UI 不卡死 |
| A-04 | 问答 | P0 | 输入问题 → 检索 Top-K → 相似度低于阈值走拒答；回答**首句声明**「《课程》/ 文件名 / 第 X 页」；附引用卡片 |
| A-05 | 拒答 | P0 | 无匹配时明确回答「知识库中没有找到相关内容」，并建议导入哪类资料，禁止编造 |
| A-06 | 重建/清空 | P1 | 可对单课程重建索引；可清空知识库并二次确认 |
| A-07 | 多轮对话 | P2 | 保留上下文并改写检索 query |
| A-08 | 引用跳转 | P1 | 点击引用卡片跳转到对应文档预览并定位页码 |

### 3.7 通用 X（5 条）

| ID | 功能 | 优先级 | 验收标准 |
|---|---|---|---|

## 4. 非功能需求

| 项 | 指标 |
|---|---|
| 冷启动 | ≤ 3 秒进入首页（不含网络请求） |

## 5. 数据与目录结构

```
%Desktop%/SmartLearner/
├─ settings.json          # 主题、路径、TTL、外观
├─ courses.json           # 课程与时间
├─ keywords.json          # 关注关键词（≤6）
├─ cache/
│  ├─ hot.json
│  └─ kw_<hash>.json
├─ Documents/
│  └─ <课程名>/
│     ├─ <子文件夹>/...
│     ├─ 课件.pdf
│     └─ 笔记.md
├─ Database/
│  └─ <课程名>/
│     ├─ chunks.json      # id/课程/文件/页码/文本/hash
│     └─ vectors.bin      # float32 连续存储
├─ logs/
└─ .trash/
```

## 6. 推进节奏（建议）

**先做不确定的，再做确定的。** 最大风险是 LLM 整理质量，先用控制台原型验证 O-02/O-03，再包 UI。

| 阶段 | 内容 | 条目 |
|---|---|---|
| 一 · 地基 | 启动、顶栏、导航、路径、网络、日志、加密、原子写、异常 | S-01/02/03/05、T-01/02、X-01~05（10） |
| 二 · 核心 AI | 整理全链路（抽取→生成→渲染→目录→导出） | O-01~05、O-07~09（8） |
| 三 · 书僮 | 建库、索引、问答、拒答 | A-01~05（5） |
| 四 · 课程文档 | 文件夹、导入、预览、笔记 | C-01/02/03/05/06/07（6） |
| 五 · 首页 | 课表、热榜、跳转、离线态 | H-01~05、H-08、H-09（7） |
| 六 · 打磨 | 主题、缓存、动效、空态 | S-04 等 P1 |

**时间不够时的砍法顺序**：H-09 细化 → C-07 笔记编辑 → A-03 进度条 → O-05 来源页码 → H-05 热榜。

## 7. 风险清单

| 风险 | 影响 | 对策 |
|---|---|---|
| LLM 整理质量不稳 | 核心演示翻车 | 固定 prompt + 低温度 + 允许重新生成 + 来源页码可核查 |
| 长文档超 token 上限 | 生成中断 | 按章分块、逐块生成、最后合并 |
| 知乎额度/限流 | 首页空白 | 缓存 + 节流 + 离线态兜底 |
| 嵌入接口限流/成本 | 建库失败 | 分批 + 重试 + 增量索引 |
| 现场无网 | 演示失败 | 离线可启动 + 预生成演示数据 |
| 单人时间不足 | 功能做不完 | 按第 6 节顺序推进，P1 随时可砍 |
